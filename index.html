Nigeria Public Project Accountability Intelligence System

Overview

A data analytics project that examines public project information from Anambra State, Nigeria, to show how data can support transparency, accountability and project monitoring. It assesses reporting quality, implementation status and progress information, and identifies records that need further review.

Business problem

Monitoring public projects depends on records that are complete and consistent. Missing information, and gaps between reported progress and status, make it hard to tell whether projects are moving as reported. This project tests how structured analysis can surface those issues.

Key findings

Progress reporting

Of the 123 In-progress projects, only 47 carry a reported progress value. Among those 47, mean progress is 54.19% and the median is 65%, ranging from 0% to 100%. The other 76 in-progress records have no value, and none of the 78 completed projects has a recorded progress value.

One record flagged for review. Project PRJ-2026-000085 (Njikoka LGA) is marked In progress with 100% reported progress. This is a data consistency flag. It is not evidence of fraud, misconduct or project failure, and it needs verification before any conclusion is drawn.

Employee Retention Intelligence and Attrition Early Warning System

Synthetic data. Every employee, experience score and resignation in this project is simulated. The results do not describe real employees and do not establish real-world cause and effect.

Overview

A workforce analytics project that simulates employee history, experience indicators and resignations, then tests whether machine learning can flag employees who might leave within six months. Version 2 added a structured monthly employee-experience simulation. Version 1 is preserved in the repository as part of the development history.

Business problem

Turnover affects productivity, recruitment cost, knowledge retention and stability. Historical resignation counts show what happened but say little about changing employee experience. The project explores how workforce data and modelling could support earlier identification of retention risk.

Target and validation design

Each employee-month is labelled positive if an exit occurs within the next six months, negative if no exit occurs and the full six-month window is observed, and censored if the window is incomplete. Censored rows are excluded, which avoids treating unobserved futures as stays. Of 14,226 eligible observations, 652 are positive and 13,574 negative; 9,956 are censored.

Logistic Regression scored best of the four on the holdout set, but its discrimination is weak. At the default threshold it identified 106 of 264 positive observations while producing 2,671 false positives. Positive prevalence in the test set is about 3.50% and PR-AUC is about 4.23%, so the gain over the baseline is modest.
